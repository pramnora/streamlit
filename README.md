## Explaining more about Steamlit/and, how it is used

Streamlit, is FREE...; and, it comes with its own code library...   

**NOTE**: Streamlit is often abbreviated to become just 'st'...;  
this is done in order to make typing less.  

The first line of code is, usually, to import the streamlit library:    

import streamlit as st  

Then, that line might be followed by important any other libraries your program may wish to use:   

import streamlit as st  
import numpy as np  
-etc.  

### Stream lit objects...

- st.title()  
- st.header()  
- st.markdown()  
- st.write()  
- st.slider()  
- st.button()  
- etc.
